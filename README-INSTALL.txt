SUENYO OS — INSTALLATION GRATUITE

1) Crée un compte GitHub (si tu n'en as pas) sur https://github.com
2) Crée un nouveau repository (New repository), nommé par exemple suenyo-os.
   Mets-le en Public pour utiliser GitHub Pages gratuitement.
3) Dans le repository, clique Add file > Upload files.
4) Dézippe ce pack et téléverse TOUS les fichiers qui se trouvent à l'intérieur du dossier suenyo_os
   (index.html, manifest.webmanifest, sw.js et le dossier icons) directement à la racine du repository.
5) Clique Commit changes.
6) Ouvre Settings > Pages.
7) Sous Build and deployment, choisis Deploy from a branch.
8) Branch: main ; Folder: /(root), puis Save.
9) Attends la publication. Le lien sera du type https://TON-USERNAME.github.io/suenyo-os/
   (GitHub affichera le lien exact dans Settings > Pages).
10) Sur iPhone, ouvre ce lien dans Safari > Partager > Ajouter à l'écran d'accueil.

Note: Cette version fonctionne comme prototype local dans le navigateur. GitHub Pages héberge les fichiers,
mais ne fournit pas de comptes, base de données ni synchronisation entre deux utilisateurs.
